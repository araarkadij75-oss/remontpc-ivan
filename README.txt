Сайт «Компьютерный мастер Иван» — современный лендинг (Apple-like) с мультяшным логотипом.
Файлы:
- index.html, style.css, logo.svg, og-image.png
- блог: /blog/*.html
- sitemap.xml, robots.txt, vercel.json

Инструкции по деплою:
1) Создать репозиторий на GitHub и загрузить файлы.
2) Подключить репозиторий в Vercel (Import Project -> GitHub -> выберите репозиторий).
3) В Vercel нажать Deploy.

Замены:
- В index.html замените domain_placeholder на реальный домен и замените og-image URL.
- Подключите Google Analytics и Yandex.Metrika, заменив маркеры в head.
